The current [system documentation](../../DOCUMENTATION.md) describes the inspected implementation; these retained images may show earlier interfaces. The cursor was kept outside every retained frame. The `teacher-guide-*` images show a real signed-in teacher panel with an assigned Science class. The `admin-guide-*` images show the administrator panel with the same temporary class. Guardian contacts have no workspace. Account activation and password recovery images show their forms only. No stock or fabricated images are stored here.
